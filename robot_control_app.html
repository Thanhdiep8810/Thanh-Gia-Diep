4.1 Architecture & Design

The RoboDeliver Control Application acts as the primary telemetry and command interface between the operator and the autonomous delivery network. The architecture utilizes a mobile-first, single-page application (SPA) design framework.

4.2 Task Execution Flow

1. Dashboard: Serves as the primary HUD. Features real-time quantitative readouts for internal payload temperature, battery power levels, and hardware statuses.

2. Route Planning: Features an interactive spatial map of the campus facility. The operator taps a desired destination node to calculate a route preview and initiate autonomous transport.

3. Access Management: Provides a localized database interface for Role-Based Access Control (RBAC). System administrators can dynamically modify security clearances.

4.3 Physical-to-Digital Sync

1. Localized Loading: The user manually opens the wooden lid and places the sample inside the orange Peltier housing, then presses the physical push-button. The physical LCD updates to "Locked", and the app instantly mirrors this state over Wi-Fi.

2. Remote Dispatch: The operator taps "Initiate Transport". The app transitions to a live progress bar, and the command triggers the physical robot's DC motors.

3. Dual-Factor Retrieval: The recipient taps their physical One Card against the robot's local RFID scanner. The physical LCD updates to "Unlocked", the servo disengages, and a success signal is pushed to the cloud app log.
